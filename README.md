# Customer Shopping Behavior Analytics Dashboard

## Overview

This project demonstrates an end-to-end Data Analytics workflow using Python, PostgreSQL, SQL, and Power BI. The objective was to analyze customer shopping behavior, uncover purchasing patterns, and build an interactive dashboard that supports business decision-making.

The project covers the complete analytics lifecycle:

**Data Collection → Data Cleaning → Exploratory Data Analysis (EDA) → Feature Engineering → PostgreSQL Analysis → Power BI Dashboard**

---

## Business Problem

Retail businesses generate large volumes of customer transaction data but often struggle to convert it into actionable insights.

This project aims to answer key business questions such as:

* Which customer segments generate the most revenue?
* Do subscribers spend more than non-subscribers?
* Which products receive the highest ratings?
* How effective are discounts in driving purchases?
* What customer groups contribute the most revenue?

## Data Cleaning & Preparation

Several preprocessing steps were performed to improve data quality:

### Missing Value Treatment

* Identified missing values in the `review_rating` column.
* Imputed missing ratings using the median rating within each product category.

### Data Standardization

* Converted column names to snake_case format.
* Renamed columns for improved readability.

### Redundant Feature Removal

* Verified that `promo_code_used` contained identical information to `discount_applied`.
* Removed the redundant column.

---

## Feature Engineering

To support deeper analysis, additional features were created:

### Age Segmentation

Created an `age_group` column using quartile-based segmentation:

* Young Adult
* Adult
* Middle-aged
* Senior

### Purchase Frequency Mapping

Converted purchase frequency categories into numerical values representing days between purchases.

Examples:

| Frequency   | Days |
| ----------- | ---- |
| Weekly      | 7    |
| Fortnightly | 14   |
| Monthly     | 30   |
| Quarterly   | 90   |
| Annually    | 365  |

## How to Run

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/customer-shopping-analytics.git
cd customer-shopping-analytics
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run Jupyter Notebook

```bash
jupyter notebook
```

Execute the notebook to:

* Load dataset
* Perform EDA
* Clean data
* Create engineered features
* Export data to PostgreSQL

### 4. Execute SQL Queries

Run the SQL scripts against the PostgreSQL database.

### 5. Open Power BI Dashboard

Open:

```text
Customer_Analytics_Dashboard.pbix
```

Refresh the PostgreSQL connection and explore the dashboard.
